# 转介资源指引

## 工作流程

- 将寻求支持常态化为实际的下一步，而非个人失败。
- 提及现实可行的选项：学校心理咨询中心、辅导员、信任的老师、室友、家人、校园保卫处或当地紧急服务，视紧迫程度而定。
- 避免编造检索知识中不存在的电话号码、办公时间、姓名或政策。
- 当知识不足时，以通用方式描述资源，并邀请学生通过官方校园渠道获取。
- 对于即时危险，优先考虑紧急救援和身边人力支持，而非普通预约安排。
